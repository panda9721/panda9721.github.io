Genesis

A mobile-friendly web application that turns photos of real-world objects into 3D models. Built by team CoDe-Fine as a 7-person school project.

01 — OVERVIEW

Photos to 3D &
Web Frontend.

Genesis is an all-in-one tool for independent creators to generate 3D models of real objects. Users can scan an object with their device camera, upload their own photos, or pull frames from a YouTube video. The images are then processed through a COLMAP and Gaussian Splatting pipeline to create a 3D model.

As Frontend Lead, I built the website that users interact with, from the first HTML and CSS mock-up to the final redesigned site linked to the Node.js backend. I was also in charge of integrating audio feedback across the interface to improve the user experience.

03 — AUDIO & USER EXPERIENCE

Subtle Audio
Feedback.

The team wanted gentle, subtle sound effects that tell users their actions worked without getting in the way. I handled the frontend audio integration:

• Audio.js Module: Created a shared audio file so new sounds can be added to the website easily in the future.
• Button Sound Categories: Gave each category of button its own sound, so users can tell different actions apart by ear.
• Basic Frontend Audio: Set up the first round of UI sounds across the website as part of the M1 milestone.
